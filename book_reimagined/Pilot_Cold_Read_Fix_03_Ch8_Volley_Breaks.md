# Pilot — Cold Read Finding #3 (Dialogue Register), Ch8 mechanical fix

**Source:** follow-up cold read rated finding #3 the weakest result — vocabulary changes to 4 characters didn't touch the underlying exchange-structure tic. User approved a mechanical survey to find true worst offenders by consecutive-short-dialogue-line count, rather than continuing to spot-fix scenes that read fine in isolation.

**Survey method:** wrote a script counting runs of 4+ consecutive paragraphs that are short (≤16 words) and start with a quote mark, across the full manuscript. Found 204 such runs, 1,121 paragraphs total. Chapter 8 ("Public Detection Threshold" — Malcolm and Naomi's first meeting, phone call then in-person) is the single worst chapter: six separate runs of 8–11 consecutive volleys.

**Approach:** this scene's terseness is partly earned characterization — two trained, guarded professionals testing each other for the first time — so I'm not rewriting the dialogue itself, which multiple close reads this session have shown works well line-by-line. Instead: one physical/sensory beat inserted at the midpoint of each long run, reusing elements the scene has already established (the cleaver, the tea tin, the folder, the phone call's dishes/faucet, the market crowd) rather than inventing new business. This mechanically splits each long run into two shorter ones — directly targeting what the survey measured — without cutting or altering any existing line.
